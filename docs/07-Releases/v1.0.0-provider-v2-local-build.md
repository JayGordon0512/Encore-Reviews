## Release Notes

The provider-neutral TicketPal hand-off is implemented locally for consented
review eligibility and withdrawal. Encore remains the owner of reviewer
identity, invitation scheduling and review-domain state.

## Architecture Changes

ADR-016 through ADR-018 are implemented as proposed direction but remain
Proposed pending formal approval. Existing TicketPal routes remain unchanged.

## Operational Changes

The build adds scoped credentials, neutral mappings, nonce/idempotency evidence,
protected reviewer contact, consent, eligibility, invitation schedules, audit
evidence and a transactional outbox. Provider secrets are referenced rather
than stored in business tables.

## Breaking Changes

None while the v2 ingress flag remains disabled.

## Migration Notes

Three additive migrations create the Release 1 foundation. Clean PostgreSQL 18
migration and rollback/reapply were verified against an isolated database.
Legacy tables and columns are retained.

## Verification

- all 15 immutable fixtures pass through the real HTTP boundary;
- cross-tenant mappings fail at database-constraint level;
- failed domain transactions leave no idempotency, contact, consent,
  eligibility, invitation, audit or outbox state;
- security nonce/journal evidence survives domain rollback;
- raw bodies, signatures, secrets and reviewer email are absent from journal
  and outbox evidence;
- the complete local application test suite passes.

## Known Issues

Production secret-manager wiring, mapping reconciliation, operated outbox
workers, invitation token delivery, retention approval and joint TicketPal
release evidence remain gated work.

## Deployment Notes

Do not deploy or activate this record as Release 1. Both
`ENCORE_PROVIDER_V2_INGRESS_ENABLED` and
`ENCORE_PROVIDER_V2_INVITATION_ISSUING_ENABLED` remain `false`. Disabled v2
routes return HTTP 404 before authentication or domain work.
